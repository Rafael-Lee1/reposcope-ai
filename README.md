# RepoScope AI

Aplicação de análise técnica de repositórios GitHub.

## Objetivo

Demonstrar uma arquitetura moderna de aplicação Full Stack
com infraestrutura Serverless na AWS provisionada באמצעות Terraform.

## Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- Python
- FastAPI

### Cloud
- AWS Lambda
- API Gateway
- CloudWatch

### Infrastructure as Code
- Terraform

### DevOps
- GitHub Actions

## Funcionalidades planejadas

- Consulta de repositórios GitHub
- Análise de linguagens
- Métricas de atividade
- Informações do repositório
- Análise técnica complementar
- Dashboard interativo

## Princípios

- Baixo custo
- Arquitetura Serverless
- Infraestrutura reproduzível
- Segurança
- Menor privilégio
- Aplicação funcional
